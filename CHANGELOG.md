# Changelog

## v3.1.0 — 2026-10-05

- Reorganized the application into three workspaces: capture/open, edit settings, and export/install. Server configurations have a separate workspace.
- Added vertical settings categories with counts, clearer section filters, profile options and optional technical inspection. Source file checksums and commands stay available without filling the normal editing view.
- Separated capture-account selection from installation destinations. Steam selections survive language changes; search and modification filters reset when opening a different profile.
- Added a dedicated export/install page with bundle contents, destination controls and last-installation restoration.
- Updated bilingual guides, screenshots and desktop workflow checks. The packaged application uses its own KeyValues parser.

## v3.0.0 — 2026-10-05

- Added the offline Windows application with Steam detection, complete VCFG/video capture and reusable profiles.
- Added value editing, key reassignment, player slots, bilingual categories and portable autoexec generation from captured settings.
- Added video merging, complete restoration, installation previews, automatic backups, failure recovery and guarded rollback.
- Added separate practice/surf/bunnyhop/KZ configuration bundles, CS2KZ plugin configuration and setup instructions.
- Added source-preservation, export, restoration and isolated desktop tests.
